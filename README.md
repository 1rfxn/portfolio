# Irfan Basha — Portfolio
Run: `npm install` then `npm run dev`. Build: `npm run build`. Deploy: push to GitHub and import in Vercel (framework: Vite).

- **Photo:** put your photo in `src/assets/` named `profile.jpg` (or .jpeg/.png/.webp), or in `public/images/`. Restart `npm run dev` after adding it.
- **Resume:** replace `public/resume/Irfan-Basha-Resume.pdf` (keep the file name, or change `resume` in `src/data/profile.js`).
- **Content:** edit `src/data/*.js` — profile, skills, projects (GitHub links, contribution), timeline.
- **Open Graph image:** add `public/images/og.png` (1200×630).
- **Contact form:** validates, then opens the visitor's email app. For real sending, connect Formspree or EmailJS.
